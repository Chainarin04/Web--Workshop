ผลลัพธ์

โค้ด HTML

1 <img src="images/campus.jpg" alt="ภาพมหาวิทยาลัย"
   width="220">
2 <img src="images/student.jpg" alt="นักศึกษากำลังเรียน"
   width="180">
3 <img src="images/logo.png" alt="โลโกวิชา"
   height="80">
🎯 จุดประสงค์การเรียนรู้
  1. อธิบายการใช้แท็ก <a> เพื่อสร้างลิงก์ไปที่อื่นหรือเว็บอื่นแหล่งต่าง ๆ
  2. แทรกรูปภาพด้วยแท็ก <img> พร้อมกำหนดขนาดสมบูรณ์ที่ฐาน
  3. ตกแต่งลิงก์และรูปภาพด้วย CSS เพื่อความสวยงามและน่าใช้งาน
🏷 แท็กที่ใช้บ่อย
<a> href target <img> src alt width height
📋 กิจกรรมฝึกปฏิบัติ
  1. สร้างลิงก์อย่างน้อย 3 แบบ
  2. แทรกรูปภาพอย่างน้อย 2 รูป
  3. ใส่ alt ให้กับรูปภาพทุกภาพ
  4. ใส่ CSS เปลี่ยนสีลิงก์เมื่อ hover
  5. ตกแต่งรูปภาพด้วย border-radius หรือ box-shadow
  6. บันทึกไฟล์ชื่อ link-image.html
✈ สิ่งที่ต้องส่ง

ส่งไฟล์ HTML พร้อมไฟล์และรูปภาพ

i
เกร็ดความรู้

แท็ก <a> ใช้สำหรับสร้างลิงก์ (Hyperlink) เพื่อเชื่อมโยงไปยังหน้าเว็บ ไฟล์ หรือที่อยู่อีเมลต่าง ๆ โดยใช้แอตทริบิวต์ href ระบุปลายทางของลิงก์ แท็ก <img> ใช้สำหรับแทรกรูปภาพ โดยใช้แอตทริบิวต์ src ระบุแหล่งที่อยู่ของไฟล์รูปภาพ และ alt ระบุความอธิบายรูปภาพ ซึ่งสำคัญด้านการเข้าถึง (Accessibility) และช่วยแสดงข้อความเมื่อไม่สามารถโหลดรูปได้
